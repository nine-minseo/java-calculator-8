# java-calculator-precourse

입력한 문자열에서 숫자를 추출하여 더하는 계산기를 구현한다.

1. 입력

- [x]  문구(덧셈할 문자열을 입력해 주세요.)를 출력한다.
- [x]  사용자로부터 문자열을 입력받는다.

2. 구분자 처리 및 파싱

- [x]  빈 문자열 처리: 입력값이 null이거나 빈 문자열("")인 경우 0을 반환한다.
- [x]  기본 구분자 처리: 쉼표(,) 또는 콜론(:)을 기준으로 문자열을 분리한다.
- [x]  커스텀 구분자 처리:
    - [x]  문자열이 //로 시작하고 \n이 나오면, 그 사이의 문자를 커스텀 구분자로 지정한다.
    - [x]  커스텀 구분자, 쉼표(,), 콜론(:)을 모두 포함하여 문자열을 분리한다.

3. 계산

- [x]  분리된 문자열을 숫자로 변환한다.
- [x]  숫자들의 합을 구한다.

4. 출력

- [x]  연산 결과를 결과 : {숫자} 형식으로 출력한다. (예: 결과 : 6)

5. 예외 처리 (IllegalArgumentException 발생)

- [x]  분리된 숫자 중 음수가 포함된 경우.
    - [ERROR] 음수는 입력할 수 없습니다.
- [x]  구분자를 제외한 문자가 숫자가 아닌 경우 (예: 1,a,3).
    - [ERROR] 구분자 외의 문자가 포함되어 있습니다.
- [x]  커스텀 구분자 형식이 올바르지 않거나, 닫는 구문(\n)이 없는 경우.
    - [ERROR] 커스텀 구분자 형식이 올바르지 않습니다.
